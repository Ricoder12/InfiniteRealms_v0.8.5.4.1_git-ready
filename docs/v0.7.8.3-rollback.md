# v0.7.8.3 Rollback

## Prior accepted build

Use `InfiniteRealms_v0.7.8.2_rollback.html`, copied byte-for-byte from the accepted v0.7.8.2 standalone build. Its SHA-256 is `233d9537b55c504ac91882ae150d16d2857eca8c621385b6b6755e68223a9737` and is recorded in `docs/v0.7.8.3-sha256sums.txt`.

The last verified pre-v0.7.7 comparison baseline is `InfiniteRealms_v0.7.6.6_pre-v0.7.7-baseline.html`. It is preserved separately; do not substitute it for the immediate rollback when comparing v0.7.8.3 with v0.7.8.2.

## Safe procedure

1. Close the running game tab.
2. Keep a backup copy of any player save/export before swapping builds.
3. Open `InfiniteRealms_v0.7.8.2_rollback.html` (or the identically hashed `InfiniteRealms_v0.7.8.2_rollback.html` convenience artifact).
4. Load the player's save and confirm character, site, discovery and inventory data. The v0.7.8.2 build does not understand v0.7.8.3 subregion fields; if a save contains custom nested regions, preserve the original save and do not re-save it from the older build. Normal v0.7.8.3 generated worlds have empty `subregions[]` unless later content adds them.

A rollback is a file-level restoration, not a guarantee that a save edited by a future version can be losslessly round-tripped by every earlier version.
