# Infinite Realms v0.7.6.5 — Change Log

## Added
- `js/game/41-monster-habitats-v0.7.6.5.js`: an authoritative profile for all 16 fixed enemy/boss definitions, habitat validation, compatible encounter filtering, and risk/Combat gates for uncontrolled high-threat appearances.
- `tests/v0.7.6.5-monster-habitats.test.js`: 28 focused checks for habitat definitions, all supported biome pools, beginner-area safeguards, hunting/scouting selection, boss flows, loot/material delivery, old saves, and world-generation parity.
- `docs/v0.7.6.5-enemy-habitat-reference.md`, `docs/v0.7.6.5-change-log.md`, `docs/v0.7.6.5-test-report.md`, `docs/v0.7.6.5-test-run-log.txt`, `docs/v0.7.6.5-standalone-smoke.js`, and `docs/v0.7.6.5-standalone-smoke.log`.

## Habitat reconciliation
- Desert: remove Slime from its normal encounter pool; retain Bandit and Thief for trade routes and Boar for desert-fringe habitat.
- Thief and Boar: add Desert to their runtime biome metadata to match the existing Desert encounter table.
- River: add River to Wolf and Spider runtime biome metadata to match the existing River encounter table.
- Other existing biome encounter pools retain their roster and ordering.

## Integration
- Existing normal/random fallback and scouting encounter selection now use habitat-compatible candidates.
- Existing hunt selection and the life-path trail event use only eligible hunt targets in the current biome; explicit player-selected hunts remain deliberate encounters.
- Settlement-specific thief/bandit/goblin and negative-reputation guard rules remain in place.
- Guardian and Dragon remain out of normal random pools; explicit dungeon boss / scripted combat paths continue through the original `startCombat`, combat-end, and reward pipeline.
- Existing enemy stats, combat scaling formulas, loot tables, reward delivery, inventory schemas, world-generation logic, map presentation, and save schemas are unchanged.

## Files and versions
- New game module is loaded immediately before `js/game/27-boot.js`.
- `index.html` title updated to v0.7.6.5 and references the new module.
- Earlier standalone builds remain unchanged. The accepted v0.7.6.4 standalone and source archive are included under `backups/` in the source package.
