# v0.8.3.5 Rank Requirements and Examinations

## Approved rank requirements

Rank thresholds are cumulative minimums. They do not automatically promote a character; an authorized examiner must record a passing records-review examination, which is saved together with the promotion.

| Target | Unique completed templates | Completed duties | Adventurers' standing | Exam |
|---|---:|---:|---:|---|
| E | 0 (not required) | 3 | 0 | Required |
| D | 1 | 5 | 10 | Required |
| C | 2 | 8 | 20 | Required |
| B | 2 | 12 | 30 | Required |
| A | 3 | 16 | 40 | Required |
| S | 3 | 20 | 50 | Required |
| SS | 3 | 25 | 65 | Required |
| SSS | All 3 | 100 | 90 | Required |

Only `route-survey`, `monster-signs`, and `supply-ledger` count. Each template counts once across guild branches, and only after its completed contract has a valid finalized reward receipt. Duties count unique completed duty-instance IDs. Accepted, active, failed, expired, incomplete, or duplicated duties do not count. Existing duty credits and daily caps are unchanged. Missing contract history is unknown for ranks that require contract evidence; E does not require contract evidence. Missing standing remains unknown, not zero.

SSS has no global top-five requirement. There is no demotion policy in this update; existing SSS holders can remain outside any informational top-five list. The global leaderboard is not implemented and requires the separately scoped roster foundation.

## Examination records

Examinations are records reviews only. The examiner records `PASS` or `FAIL`. Retries have no fee or cooldown. An ineligible character cannot receive a failed result. A passing result and the next-rank promotion are committed together. A failed result records no promotion. The examination and promotion histories are stored under the character; `currentRank` remains in the existing `adventurerProgression` record.

The first recorded examination assigns a stable `adventurerId` to `adventurerProgression`. A separate character-owned `adventurerRankRecords` object stores schema 1, examination records, promotion records, and monotonic sequence counters. Malformed records are quarantined and preserved; rank operations then fail closed. Records include stable character and NPC IDs, target rank, outcome, timestamp, and in-game day.

## Examiner authority data requirement

Examiner authorization reads, but does not create or populate, an optional authoritative world record:

```json
{
  "associationLeadership": {
    "schema": 1,
    "grandmasterNpcId": "<existing stable NPC ID>",
    "delegatedExaminerNpcIds": ["<existing Adventurers' Guild Guildmaster NPC ID>"]
  }
}
```

The Grandmaster ID must resolve to one existing NPC marked `associationRole: "grandmaster"`; exactly one such role record may exist. Delegated IDs must resolve to existing Adventurers' Guild Guildmaster NPCs. The examiner must also be present at the current location when conducting the review. Missing or ambiguous leadership data leaves examination unavailable. The accepted v0.8.3.4 world-generation and NPC sources do not currently register a Grandmaster or delegated examiners, so new game worlds need an authoritative leadership-data source before examinations can be used.

No NPC, rank, contract history, duty history, standing, or examination result is generated by this update. It does not implement a global adventurer roster or informational leaderboard.
