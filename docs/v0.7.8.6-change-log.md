# Infinite Realms v0.7.8.6 — World Generation Integration

- Added `js/game/55-world-political-generation-v0.7.8.6.js`, loaded after political entity, regional hierarchy, and leadership modules.
- New procedural worlds receive a small deterministic set of political entities when enough geographic sites and stable IDs exist.
- Entity IDs and selection use the stable world ID/seed and stable region IDs; capitals reference existing site `geoId` values.
- Existing non-empty `world.polities` are left untouched. Save normalization does not invoke political generation.
- Region ownership/governance metadata is attached to existing region records; sites and routes are not copied or regenerated.
- Generation validates all capitals before committing and rolls back political additions if final political validation fails.
- No wars, diplomacy, conquest, faction membership, or political gameplay was added.

## Baseline note
The requested accepted v0.7.8.5 build was available as a candidate baseline, but the preceding release report explicitly marked formal acceptance pending. This build uses that v0.7.8.5 candidate source; the preserved rollback is the candidate baseline, not a separately confirmed formally accepted release.
