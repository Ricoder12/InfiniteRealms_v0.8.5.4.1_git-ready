# Infinite Realms v0.7.8.2 — Rollback

## Accepted starting build

`InfiniteRealms_v0.7.7.9_accepted_baseline.html` is the exact v0.7.7.9 standalone that was used as the v0.7.8.1 audit starting point. Its SHA-256 is recorded in the release manifest and checksum list.

## Rollback procedure

1. Stop using the v0.7.8.2 standalone.
2. Open `InfiniteRealms_v0.7.7.9_rollback.html` (a byte-for-byte copy of the accepted v0.7.7.9 baseline).
3. Existing saves do not require conversion to use the old build. The new `world.polities` field is additive and unused by v0.7.7.9. For the most conservative rollback, retain a separate backup of any JSON save before opening it in another build.

The source and historical baseline are preserved in the v0.7.8.2 source archive. No migration or rewrite of geography IDs is needed to roll back.
