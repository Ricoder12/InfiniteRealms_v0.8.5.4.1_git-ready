# v0.7.7.8 Rollback Instructions

## Accepted rollback
Use `backups/InfiniteRealms_v0.7.7.7_accepted_baseline.html` or the separately packaged `InfiniteRealms_v0.7.7.7_rollback.html` to return to the accepted v0.7.7.7 build. The exported rollback file was copied from the accepted standalone and compared byte-for-byte with it during packaging.

## Pre-v0.7.7 baseline
The source project also retains `backups/InfiniteRealms_v0.7.6.6_accepted_baseline.html`, which was used to generate a real browser save for compatibility testing.

## How to roll back
1. Download the v0.7.7.7 rollback HTML.
2. Close the current game tab.
3. Open the rollback file in the browser. Browser-local saves may be origin/file-URL-specific; keep a backup of any exported save before switching builds or storage contexts.
4. Load the intended save and verify character, location, discovery, equipment, relationships, and progression before continuing.

The compatibility update does not intentionally introduce a new save schema, but always retain an exported save copy before trying rollback across browser storage contexts.
