# v0.7.6.6 — Rollback Instructions

1. Close the game tab before replacing files.
2. Restore `InfiniteRealms_v0.7.6.5_backup.html` (or `backups/InfiniteRealms_v0.7.6.5_accepted_baseline.html`) as the playable standalone build.
3. Keep the v0.7.6.6 HTML and source ZIP separately if you want to inspect the changes later.
4. Do not delete or rewrite your browser's saved game as part of rollback. v0.7.6.6 adds no save-schema version and does not regenerate saved worlds; nevertheless, keep an exported save copy before testing builds.

The rollback file is a byte-for-byte copy of the accepted `/mnt/data/InfiniteRealms_v0.7.6.5.html` standalone artifact. SHA-256 is recorded in `docs/v0.7.6.6-baseline-hashes.txt`.
