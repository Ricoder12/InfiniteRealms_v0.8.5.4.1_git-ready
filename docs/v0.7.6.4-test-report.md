## Limitations / known issues

- A full interactive browser session was not verified in this run. Prior environment checks showed Chromium unavailable/timing out even on a blank page, so the current report does not claim live-browser acceptance.
- Save compatibility was checked through the existing synthetic legacy-save fixtures and production normalizer, not a user-exported historical save file.
- Balance values are intentionally modest starting values; subjective gameplay balance still benefits from a player smoke test across several races and biomes.
- Historical coverage is limited to the regression suites present in this project (v0.7.3.1 onward for NPC/reputation tests, then v0.7.5.1 onward for world/biome systems); there are no dedicated automated test suites for every earlier v0.1–v0.7.2 feature.
