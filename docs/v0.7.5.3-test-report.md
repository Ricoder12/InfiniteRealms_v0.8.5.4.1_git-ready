## v0.7.5.3 coverage

The 14 new geography checks cover reuse of v0.7.5.2 stable IDs, versioned geographic metadata, valid region parents, reference-only settlement and POI registries, wilderness/uninhabited sites, global and local route endpoints, current/known/visited/discovered location access, travel-property compatibility, duplicate connection detection, dangling endpoints/parents, parent cycles, isolated locations with no outgoing routes, JSON save/load state, and idempotent normalization.

The integration check calls the production `normalizeSave()` implementation on a serialized save and verifies the current location, visited state, known destinations, a discovery, site references, route references, and the final geography validation report. The existing normalizer may add reachable neighbor locations to `known`; the test correctly verifies that prior known locations remain known rather than requiring an unchanged array length.
