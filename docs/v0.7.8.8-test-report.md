## Regression coverage

The 33 Node files cover political entity validation, regional hierarchy, generation determinism, geography preservation, save normalization, map discovery rules, travel and route behavior, biomes, racial affinity, NPC relationships/reputation, combat, inventory, jobs, crafting, character status, and old-save compatibility. Individual test output is in `v0.7.8.8-node-regression.log`.

Standalone integrity checks in `v0.7.8.8-standalone-smoke.log` confirm the built HTML has no external script or stylesheet dependencies, retains map/travel integration, and advertises the v0.7.8.8 title.

- Python is unavailable, so browser-script Python syntax checks were not run.
- No actual player-exported save was supplied. Compatibility evidence comes from generated older-version fixtures.
