# Infinite Realms v0.7.6.5 — Rollback Instructions

## Fast rollback (playable standalone)
Open or restore `backups/InfiniteRealms_v0.7.6.4_accepted_baseline.html`. Its SHA-256 is recorded in `docs/v0.7.6.5-test-report.md`; it is the accepted v0.7.6.4 standalone copied before v0.7.6.5 changes.

## Source-project rollback
Use `backups/InfiniteRealms_v0.7.6.4_accepted_source.zip` as the entire pre-change source project. This is preferable to manually undoing the current index changes. It includes the previously accepted source modules and test suite without v0.7.6.5.

## Manual reversal (not recommended)
1. Remove the v0.7.6.5 script reference from `index.html` and restore its title to v0.7.6.4.
2. Remove `js/game/41-monster-habitats-v0.7.6.5.js` and `tests/v0.7.6.5-monster-habitats.test.js`.
3. Restore the prior biome/enemy runtime state by rebuilding from the accepted v0.7.6.4 source archive. Do not rely on editing the new module alone if the bundle was already built.
4. Rebuild and rerun the previous regression suite.

The v0.7.6.5 logic is runtime-only. It does not write a habitat field into saves, so no save migration or reverse migration is required.
