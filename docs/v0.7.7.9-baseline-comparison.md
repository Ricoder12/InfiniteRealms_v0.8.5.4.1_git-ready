## Behavioral comparison

The v0.7.7.9 production delta from accepted v0.7.7.8 is release metadata only. The final browser and Node regressions exercised the three map views, discovery and map state, valid/disconnected travel, Character summary refresh, save normalization, and gameplay modules. The compatibility browser suite generated saves using accepted v0.7.6.6 and v0.7.7.7 code, then loaded and continued them with v0.7.7.9. No representative user-exported save was available, so compatibility with arbitrary player saves remains unconfirmed.
