# v0.7.7.5 Rollback Instructions

The accepted v0.7.7.4 standalone baseline is archived at `backups/InfiniteRealms_v0.7.7.4_accepted_baseline.html` and is also delivered as `InfiniteRealms_v0.7.7.5_backup.html`.

1. Keep a copy of any current user save/export separately before switching builds.
2. Close the v0.7.7.5 tab.
3. Open the rollback HTML (`InfiniteRealms_v0.7.7.5_backup.html`) in the browser.
4. If browser storage was shared between versions and an unexpected issue occurs, use a fresh browser profile or export the current save before testing recovery. Do not delete browser storage as a first-line rollback step.
5. To return to v0.7.7.5, open `InfiniteRealms_v0.7.7.5.html` again.

The rollback HTML is intended to be byte-identical to the accepted v0.7.7.4 artifact. Its SHA-256 is recorded in `InfiniteRealms_v0.7.7.5_Release_Manifest.txt`.
