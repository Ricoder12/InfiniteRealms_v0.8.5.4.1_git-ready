Use `InfiniteRealms_v0.7.6.4_backup.html` (the accepted v0.7.6.3 standalone HTML) to return to the pre-affinity build. Its SHA-256 is:

`537a6101800d303a0e96e9c3946e2c3061bfc9a591021a75c676da91f2567c48`

## Source-project rollback
If reverting the split source project, restore the accepted v0.7.6.3 project backup, then remove the v0.7.6.4 script include and module. Also revert the two integration edits in `js/game/05-progression-economy-v0.4.js` and `js/game/39-environmental-hazards-v0.7.6.3.js`. Rebuild with `node build.js`.

Do not delete the accepted baseline or overwrite it with the new build. This version adds no save fields, so rolling back does not require save migration. The safest option for a clean comparison is to load the preserved v0.7.6.3 HTML in a separate file/browser profile rather than overwrite an active save.
