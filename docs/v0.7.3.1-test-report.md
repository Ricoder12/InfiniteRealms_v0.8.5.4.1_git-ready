## Known limitations
- The test harness verifies the patch's data-handling functions, not every game interaction or real browser storage path.
- Memory history remains limited to the existing five-memory per-NPC cap and journal cap.
- Existing save normalization and migration code is preserved; malformed or manually edited saves beyond normal legacy shapes are not guaranteed.
- Please test a copy of your real save in a regular browser before replacing your daily working file.
