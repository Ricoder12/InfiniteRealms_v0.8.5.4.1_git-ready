# v0.7.5.2 Rollback

The immediate rollback target is `backups/InfiniteRealms_v0.7.3.6_baseline.html`, the untouched accepted standalone HTML.

To disable only the identifier patch in the source tree:

1. Remove the `<script src="js/game/33-stable-geographic-identifiers-v0.7.5.2.js"></script>` line from `index.html`.
2. Delete `js/game/33-stable-geographic-identifiers-v0.7.5.2.js`.
3. Restore the original global route lookup expressions in `js/game/03-stability-v0.2.1.js` and `js/game/06-talents-spells-factions-v0.5.js` to `const a=r.sites[e.a],b=r.sites[e.b]` and retain their existing invalid-endpoint guard.
4. Restore the version title in `index.html` to `Infinite Realms — Version 0.7.3.6`.
5. Run `node build.js`.

No new geographic IDs were added to existing user saves by this work session; the patch is applied at runtime when the game generates or normalizes a world. If a player has saved after running v0.7.5.2, removing the patch simply leaves the extra `world.id`, `region.id`, `site.geoId`, and route metadata as ignored additional fields. Existing legacy fields are retained, so the older game can continue to resolve locations through `site.id`, `route.to`, and `a` / `b` as before.
