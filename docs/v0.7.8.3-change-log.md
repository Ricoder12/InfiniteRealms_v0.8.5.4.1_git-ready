# Infinite Realms v0.7.8.3 — Change Log

## Implementation

1. Added `js/game/53-regional-hierarchy-v0.7.8.3.js` and loaded it after the political entity foundation, before application boot.
2. Added metadata-only `subregions[]`, stable child region IDs, structural `parentRegionId`, independent country/continent references, and nullable `ownerPolityId`/`governingPolityId` references.
3. Added safe hierarchy initialization, a flattened reference-only `world.geography.regionIds` index, location region resolution/assignment helpers, and duplicate/missing/invalid reference validation.
4. Extended the political entity lookup to recognize nested geographic regions without copying sites or routes.
5. Fixed legacy save preparation that previously flattened valid non-primary `site.regionId` assignments to the root. Only uniquely resolvable region assignments are restored; malformed assignments still receive the existing safe primary-region repair.
6. Updated release title/shell/Character status branding to v0.7.8.3.
7. Updated the historical standalone smoke test's title assertion to match the current candidate release. Added v0.7.8.3 regional hierarchy, save compatibility, travel, and unified UI browser tests.

## Explicitly not implemented

No polity seeding, regional ownership gameplay, country/continent population, capital or ruler generation, faction membership, diplomacy, wars, conquest, dynamic borders, travel formula changes, or map-layout changes.
