# Infinite Realms v0.7.7.4 — Rollback Instructions

The accepted starting build is preserved as `backups/InfiniteRealms_v0.7.7.3_accepted_baseline.html` and is also delivered as `/mnt/data/InfiniteRealms_v0.7.7.4_backup.html`.

To roll back, close the newer standalone game and open the v0.7.7.3 baseline file. If keeping a working folder, replace the current standalone HTML with the baseline rather than trying to reverse the local map module by hand. The v0.7.7.4 additions do not add save-schema fields, and the new map scene does not write to saved world state.

The delivered rollback artifact is intended to be byte-identical to the accepted `/mnt/data/InfiniteRealms_v0.7.7.3.html`. Its SHA-256 hash is recorded in `/mnt/data/InfiniteRealms_v0.7.7.4_Release_Manifest.txt` and in the source ZIP's `docs/v0.7.7.4-artifact-manifest.txt`.
