## Not tested / limitations

- No player-exported or long-running production save was independently loaded for this release. The browser harness uses an in-memory localStorage shim and a deterministic fresh game.
- Tests do not establish that buildings correspond to actual local coordinates; such coordinates are not in the data model. Settlement houses, paths, green/plaza and terrain props are illustrative only.
- There is no walkable local grid, local building interior, exact player tile, traced road or physical crossing geometry. Existing route/travel logic remains authoritative.
- Current game generation has one populated region; this release does not generate new settlements or other geography.
