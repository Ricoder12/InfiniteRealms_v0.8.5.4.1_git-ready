# Infinite Realms v0.7.7.2 — World Map Architecture

## Purpose
Add an interactive world-scale map entry point and a region-level terrain view, consuming the geography already present in the accepted v0.7.7.1 build. This version prepares the experience for later world/regional/local layers without fabricating missing geography.

## Data audit and deliberate limits
The accepted generated world contains one populated primary region with 49 sites. The generator supplies `region.sites[]`, `region.routes[]`, site `x`/`y`, biomes, stable `geoId` values, and route relationships. Those `x`/`y` coordinates are regional layout positions, not world coordinates. The accepted world has empty `continents` and `countries` collections, no real world-scale position for the region, and no stored coastlines or boundary geometry. Therefore this version does not draw fabricated continents, political ownership, borders, or extra regional markers. The atlas identifies the one populated region as unlocated and not to scale.

## Presentation layers
- **World atlas:** illustrated parchment field atlas, cartographic ornament, the real populated region's name/description, current position, known biome summary, and journal-confirmed settlements/landmarks. The world canvas is explicitly an atlas index, not a false map of landmasses.
- **Regional terrain chart:** uses the current region's existing site positions and actual biome profiles for known/discovered places; actual visible route edges must resolve through existing geographic connections and `irRouteBetween`.
- **Fog:** neutral background patches use fixed presentation coordinates independent of hidden site records. Hidden sites do not produce marker nodes, names, geoIds, specific biome decoration, exact coordinate pairs, or routes to/from unknown endpoints.
- **Current location:** uses a standout marker. Dense non-current labels are hidden until selection, and markers retain titles/accessible names. The currently selected place's inspection card identifies what the player is permitted to know.

## Navigation and state
`js/game/44-world-map-v0.7.7.2.js` wraps the existing World tab renderer and actual accepted regional map section. `ir0772-open-region`, `ir0772-return-atlas`, `ir0772-inspect-location`, and `ir0772-clear-selection` update module-level UI variables only. They do not add properties to the world/save. A marker uses its actual legacy site ID and stable geographic ID. Selecting a location does not travel or consume time. The separate travel button is rendered only when the existing travel helper returns a direct route; it invokes the existing travel preview/action path.

Paid intelligence markers, where present in the accepted renderer, are read as explicit existing targets. Optional hierarchy and intelligence hooks are guarded; no missing field is synthesized into saved world geography.

## Compatibility and non-goals
- Preserve the accepted v0.7.7.1 standalone byte-for-byte as `backups/InfiniteRealms_v0.7.7.1_accepted_baseline.html`.
- Keep save schema and discovery sets unchanged.
- Do not change world generation, route rules, transport costs, travel duration, or existing exploration triggers.
- Do not add world-scale geometry or new continent/country records. A genuine continent silhouette/world positioning feature must wait for actual world-scale geography data.
- No v0.7.7.3 features are included.
