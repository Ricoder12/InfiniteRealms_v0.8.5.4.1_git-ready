2. Open the backup HTML above, or copy it to a separate working filename such as `InfiniteRealms_restore_v0.7.6.1.html`.
3. Keep player save/export files separate. Do not overwrite or delete a save while switching application versions.
4. If rolling back from the split source project instead of the standalone, restore the saved v0.7.6.1 source archive/build from your own accepted copy. Do not remove the v0.7.6.2 module from an existing folder without first making a copy.
5. If your current save behaves differently after rollback, restore from a save backup made before switching versions.
