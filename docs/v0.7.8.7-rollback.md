## How to roll back

1. Download the v0.7.8.6 map-integration rollback HTML.
2. Open it in a browser to run the previous candidate.
3. Keep the v0.7.8.7 source ZIP and save exports for investigation; do not overwrite or delete a user save while switching builds.
4. Note that save compatibility is tested via local save slots with legacy fixtures, but a user-exported save has not been independently tested in this release.

The current v0.7.8.7 standalone and accepted baseline are byte-for-byte identical, SHA-256 `161a17adfe957a231a9f34530a17529afdeaab59560e4e0a50cb2f7466d9eb71`.
