## Implementation

Added `world.v087` with schema 1, deterministic legacy-goal mapping, bounded ambition progress, event rumor references, and reciprocal settlement/faction relationship records. Save normalization preserves valid data, defaults invalid fields independently, ignores unknown identities, and performs no simulation on load.

After each successful v0.8.6 daily tick, the extension cleans and propagates active event rumors to up to two deterministic NPC recipients per settlement, advances qualifying ambitions, rewards completed ambition cycles with +2 affinity, and pairs faction alliances/rivalries from existing v0.8.6 influence. Political state is symmetric and recomputed in stable faction-ID order. Rivalries block regional merchant transfers and apply weekly influence penalties; alliances grant one capped bonus to an ally when its partner gains influence from a helped event. Regional tick rollback includes the v0.8.7 state and relationship changes.

The existing People screen now shows local ambition progress and active rumors. The Living region panel shows settlement alliances and rivalries beside existing influence values. Existing NPC goals, relationship records, faction standing, and market systems remain the authorities.
