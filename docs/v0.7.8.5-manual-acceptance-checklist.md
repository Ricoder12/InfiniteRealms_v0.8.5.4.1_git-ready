# Infinite Realms v0.7.8.5 — Manual Acceptance Checklist

Use this checklist while testing the v0.7.8.5 candidate. Check an item only after personally verifying it. Record any failure in the Notes section rather than assuming it passed.

## Important context

- [ ] Confirm the title/version reads **Infinite Realms v0.7.8.5**.
- [ ] Remember the baseline qualification: the requested v0.7.8.4 artifact was not available; this candidate was built from the latest verifiable accepted v0.7.8.3 source.
- [ ] Use a copied/test save if possible. Do not overwrite your only valuable save during acceptance testing.
- [ ] Understand that v0.7.8.5 adds **data helpers only**. It does not add a political-management screen, seed kingdoms/rulers, or visibly populate countries. Not seeing new government UI is expected.

## A. Launch and general regression

- [ ] The game opens without a blank screen or startup error.
- [ ] Start a new game and confirm character creation still completes normally.
- [ ] Load an existing test save and confirm the saved character and world open.
- [ ] Confirm the main navigation remains responsive.
- [ ] Open the World, Regional, and Local map views; none should freeze or reset the player's location.
- [ ] Select a location and inspect its details; selection should not advance time or change the player's actual location by itself.
- [ ] Preview a valid route and travel; arrival, time, energy, and travel information should update as before.
- [ ] Confirm a disconnected/invalid route is rejected safely.
- [ ] Open Character, Skills, and Inventory. Existing stats, skills, equipped items, and inventory should still be present.
- [ ] Visit People/relationships and other commonly used tabs. NPCs, relationships, reputation, jobs, crafting, and notifications should behave as before.

## B. Save and reload

- [ ] Save the test game, return to the title/menu if available, and reload the saved slot.
- [ ] After reload, confirm the current location and discovered/visited places are preserved.
- [ ] Confirm inventory, equipped items, coins, skills/progression, NPCs, relationships, and reputation have not unexpectedly reset.
- [ ] Travel once, save again, reload, and confirm the arrival location and travel progress remain correct.
- [ ] If testing an older save, confirm it loads without asking to restart or regenerate the world.

## C. Government, ruler, and capital data — expected behavior

**These checks require the bundled tests or inspection of the political records; normal gameplay does not currently expose them in a dedicated UI.** Do not mark these passed solely because the game launches.

- [ ] A political entity can have a government type and description, e.g. `monarchy` and a short description.
- [ ] A leader reference points to an existing NPC/person ID and resolves to that person's name.
- [ ] Assigning a leader does not create a second NPC or alter that person's relationship data.
- [ ] A valid capital reference resolves to the existing settlement's name; no duplicate settlement appears.
- [ ] An entity with no ruler still loads and can be summarized.
- [ ] An entity with no capital still loads and can be summarized.
- [ ] An entity with no government description still loads and can be summarized.
- [ ] A missing/invalid leader or capital reference is reported safely; it does not crash world loading or map rendering.
- [ ] A capital outside explicitly assigned territory is reported as invalid where territory is known. If territory is not assigned, the system does not invent one.
- [ ] Controlled-region counts are only reported when supported by explicit ownership/governance links; unknown territory is not presented as a confirmed zero.
- [ ] Save and reload a test political record; government type/description, leader NPC ID/title, and capital site ID remain unchanged.

## D. Confirm the scope stayed small

- [ ] No new political-management tab or interaction appeared; this is expected for v0.7.8.5.
- [ ] No rulers, capitals, kingdoms, or government types were automatically assigned to every generated world/entity.
- [ ] No elections, succession, taxes, quests, diplomacy, wars, faction membership, or political privileges appeared.
- [ ] The world map, geographic IDs, regions, routes, and physical locations have not been duplicated or regenerated as a side effect.

- [ ] For any failure, record the action taken, expected result, actual result, and whether it happened with a new game or an existing save.
- [ ] Keep the test save and browser console/logs available if a regression needs investigation.
