# Infinite Realms v0.8.2.3 — Guild Membership Services and Interactions

## Release result

Starting source: the accepted v0.8.2.2 source tree (`work/roadmap_v080`), confirmed by `index.html` title and the loaded `js/game/63-guild-services-v0.8.2.2.js` module. The source includes v0.8.0 faction definitions and the v0.8.1 organization registry.

The guild receptionist and guildmaster now expose the actual guild record, description, location, available service personnel, current eligibility, current membership, and shared Adventurers’ Guild standing. The player can inquire, join when the existing eligibility check allows it, inspect the shared membership status, and request to leave through the established confirmation dialog.

Membership still uses `character.factionMembership` and `character.factionStanding` through `ir051FactionEligibility`, `ir05JoinFaction`, and the existing faction leave handler. No membership schema or second ruleset was added. The existing single-active-faction rule remains in force; the data model does not support different per-guild membership rules or individual memberships for separate guild records. No contract board acceptance or completion, promotion, or guild-reputation consequences were added.

Inquiries report through a toast and do not create an NPC relationship or memory entry. Joining and leaving retain the established shared faction standing adjustments (+5 on joining; −10 on leaving); public reputation and personal relationship values remain unchanged.

## Known limitations

- Existing membership applies to the Adventurers’ Guild faction collectively, not to one specific guild organization. The original foundation enforces one active faction at a time; this release preserves that rule.
- The foundation exposes no guild-specific application/approval or custom eligibility records. Membership uses only currently implemented eligibility rules.
- Browser interaction and visual appearance were not manually verified in this release.
