# Infinite Realms v0.7.6.1 — Change Log

## Starting point and preservation
- Built from the accepted v0.7.5.5 standalone file/source working copy.
- Preserved the v0.7.5.5 standalone HTML unchanged as `backups/InfiniteRealms_v0.7.5.5_backup.html` and external rollback artifact `InfiniteRealms_v0.7.6.1_backup.html`.
- Retained all nine previous biome identifiers and the established stable geographic IDs. No new biome types, regions, sites, or settlements were generated for this feature.

## Changes
- Extended the existing `IR_BIOMES` registry in `js/data/world.js` with terrain tags, environmental-condition tags, generic habitat categories, weighted resource categories/items, existing forage chance values, the old gathering item pools, and the existing gathering availability rules.
- Added read-only biome resolvers/accessors for profile names, resource categories, forage/scout pools, gathering pools/eligibility, habitat tags, encounter pools, and travel context.
- Moved the two old exploration forage/scout tables and the gathering method-by-biome item pools into the one profile registry. The exact previous list entries/repetitions and existing forage modifiers were preserved.
- Updated forage, scouting, gathering, encounter lookup, travel context, map labels, adventure labels, and location information to read the authoritative profiles or the existing encounter table.
- Added `js/game/37-biome-profile-validation-v0.7.6.1.js` for non-mutating profile/world validation and diagnostics after generation and save normalization.
- Added `tests/v0.7.6.1-biome-profile-system.test.js` (21 checks).

## Explicitly unchanged
- Generated world layout, sites, biome assignments, site IDs, stable geographic IDs, route records, and save schema.
- Encounter definitions and their per-biome enemy lists; profiles reference the existing `IR_BIOME_ENEMIES` table.
- Travel distance, time, fare, transport restrictions, and danger formulas.
- Gathering costs, time, yields/chance formula, skill progression, capacity checks, and existing mining high-risk exception.
- No racial biome affinity, survival damage, ecology simulation, new creature type, map redesign, political data, faction feature, or v0.7.6.2 feature.
