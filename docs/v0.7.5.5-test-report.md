## Known issues / boundaries

1. A real browser session has not been verified, so treat the browser and real localStorage checks as open rather than passed.
2. The legacy compatibility pass cannot prove that all unprovided player saves load without loss. Keep exported backups before testing the new build on an important save.
3. Structurally unsafe geographic data may follow the existing deterministic seeded fallback. The new compatibility layer records a warning but does not implement a separate map-reconstruction/recovery wizard.
4. Invalid biome IDs or irreconcilable NPC-location refs are reported rather than guessed. They can remain as integrity errors/warnings for manual review.
5. No later-version gameplay was added. The scope remains v0.7.5.5.
