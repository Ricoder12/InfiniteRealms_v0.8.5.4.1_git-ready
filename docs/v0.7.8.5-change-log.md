# Infinite Realms v0.7.8.5 — Governments, Rulers, and Capitals

## Implemented

- Added descriptive `governmentType` metadata (monarchy, council, republic, tribal leadership, city-state administration, other) and optional `governmentDescription` to existing political entity records.
- Added optional `leaderNpcId` and `leaderTitle` references. Leader resolution uses existing character/world NPC records and the existing `world.v06.changes` persisted-person overlay; it creates no duplicate NPC/person records.
- Added `irGetPoliticalEntitySummary` to retrieve political entity ID/name/type, government description, existing capital location name, ruler name/title when resolvable, and explicit owned/governed/controlled region counts.
- Extended political entity validation for government types, optional field types, NPC leader references, capital references, and capital location relative to explicitly owned/governed territory where enough data exists.
- Extended save normalization to validate the new optional fields without a save-schema migration or forced assignments.
- Added Node and Chromium tests for complete, partial, empty, invalid, and saved/reloaded political entity records.

## Explicitly not implemented

No ruler schedules, succession, elections, royal families, leadership AI, throne interactions, quests, taxes, political privileges, diplomacy, faction membership, or UI screen were added. This version exposes summary data for a future UI but does not add political gameplay.

Requested starting version v0.7.8.4 was not available in the workspace. Candidate source was based on the latest verified v0.7.8.3 source/build; see `v0.7.8.5-baseline-qualification.md`.
