# v0.7.7.9 Testing Limitations

- No real user-exported save was supplied. Legacy compatibility was tested using saves generated through accepted v0.7.6.6 and v0.7.7.7 builds, plus a deterministic extensive-exploration fixture.
- A full unautomated player session was not performed. Browser verification was Chromium-driven using deterministic test worlds and scripted interactions.
- An aggregate browser-run invocation stalled during its travel preview step. The affected travel suite and remaining browser suites were rerun individually; the final individual run logs show all ten suites passing. The stalled aggregate invocation is not counted as a passing run.
- Historical browser harnesses were adjusted to use the current unified map controls and current visible labels. Those changes update test selectors/version expectations, not the underlying gameplay behavior.
- The current world dataset does not define true world-scale coordinates or continent geometry. The World view therefore presents the populated region as an atlas/index rather than drawing invented continent positions; connection lines remain schematic rather than surveyed road geometry. This is an explicit data limitation, not a newly introduced regression.
