# Infinite Realms v0.7.7.7 — Unified Map and Character UI Polish

## Objective
Apply one consistent visual and interaction language to the World, Regional, and Local maps and the Character Status addendum without redesigning unrelated tabs or modifying game rules.

## Changes implemented

1. **Unified map-layer control.** Added a reusable World / Regional / Local switcher above all three map views. The current layer receives a visible active state and `aria-current` / `aria-pressed` values. Native buttons retain keyboard activation. The control uses the existing transient `ir0772MapScope` state and the canonical map model; it does not move the player or advance time.
2. **Location and route states.** Harmonized current/selected marker rings and the selected route edge's color/weight. The switcher includes a concise map key distinguishing current/selected locations and recorded connection lines from surveyed roads. Existing map geometry and route graph data are untouched.
3. **Travel estimate readability.** Added spacing, borders, numeric alignment, contrast and narrow-screen behavior to the existing route estimate/details panels. The travel-preview and route-confirmation actions are the existing actions.
4. **Character status presentation.** Styled the existing appended health/energy meters and numeric displays in the same forest/gold palette, added explanatory native tooltips, and retained the original Character screen above the addendum. Detailed skills and equipment management stay in their existing screens.
5. **Keyboard and responsive polish.** Added scoped high-contrast `:focus-visible` outlines, disabled-control appearance, mobile grid behavior, and reduced-motion handling. Browser layout was checked at 390px with no horizontal overflow in the tested views.
6. **Scoped styling only.** The new stylesheet targets the map system and Character addendum. It does not add a frontend framework or external dependency and avoids broad global typography/button rules. Existing Life, Adventure, People, Journal, Skills, and Inventory navigation was smoke-tested.

## Intentional limitations

The maps continue to visualize the existing graph; the UI does not invent surveyed road geometry or new route data. Travel estimates and rules remain the accepted v0.7.7.5 implementation. Active conditions and modifiers are sourced from existing game state, not newly introduced mechanics. Automated browser runs use deterministic test data and do not substitute for a manual session using an exported player save.
