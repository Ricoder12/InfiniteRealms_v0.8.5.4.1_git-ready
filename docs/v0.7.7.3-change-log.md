# Infinite Realms v0.7.7.3 — Change Log

## Scope delivered

- Added `js/game/45-regional-map-v0.7.7.3.js` as a view-only regional/local layer loaded after the accepted v0.7.7.2 atlas and before application boot.
- Replaced the active regional renderer with a discovery-aware chart using the existing region/sites, stable geography IDs, `IR_BIOMES`, canonical `region.routes`, per-site route references, and the current route helper.
- Added a verified-edge check: an undirected connection needs both endpoint route records; an explicitly directed edge needs its recorded forward route. A line is not drawn for missing endpoints, malformed edges, absent route records, or undiscovered endpoints (except a direct destination supported by the existing intelligence UI).
- Made the directly-reachable ring rely on the same visible verified edge as the separate travel action. Selecting a node remains inspection only; travel invokes the existing action/preview path.
- Made regional labels discovery-aware and less crowded: visited/current/selected/reported labels remain visible; other known unvisited labels reveal on hover/focus. Hidden locations are omitted from markers/route geometry and their IDs, coordinates, names, and unconfirmed site details are not placed into the map markup.
- Added local view as a current-site detail sheet for existing local service data and known outgoing routes. Hidden exits are suppressed. If the current site is not visited/discovered, saved site name, settlement type, risk, description, and services remain concealed.
- Kept world, regional, and local view scope/selection in transient UI state. Valid selected `geoId` values survive view switches, and unavailable selections safely fall back to the current site.
- Removed unsupported decorative river, water-band and ridge markup from the regional chart. Biome patches are explicitly illustrative classifications; connection lines are explicitly schematic rather than traced roads.
- Added focused regional tests and live Chromium interaction checks, including mobile layout and navigation.

## Explicitly unchanged

- Travel duration, transport, danger, route eligibility, discovery rewards, combat, biome effects, and resource rules.
- World/region generation, site inventory, settlements/landmarks, route graph, political ownership, save schema, and persisted discovery state.
- No invented continents, countries, sites, local roads, houses, traced rivers/coastlines, mountain crossings, or political boundaries were added.
