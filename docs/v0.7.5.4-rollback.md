# Infinite Realms v0.7.5.4 — Rollback Instructions

## Standalone HTML rollback

1. Close the game tab and export or copy any important saves if the game still opens.
2. Replace the v0.7.5.4 HTML with the untouched `InfiniteRealms_v0.7.5.3_backup.html` file.
3. Reload the game from that prior standalone file. v0.7.5.4 does not change the save schema version, but keep a copy of the save before switching versions.

## Source project rollback

Restore the saved v0.7.5.3 source archive or remove only these v0.7.5.4 changes:

- `js/game/35-world-generation-integration-v0.7.5.4.js`
- `tests/v0.7.5.4-world-generation-integration.test.js`
- `tests/v0.7.5.4-gameplay-integration.test.js`
- `docs/v0.7.5.4-world-generation-integration.md`
- `docs/v0.7.5.4-test-report.md`
- `docs/v0.7.5.4-rollback.md`
- The v0.7.5.4 script include and title in `index.html`

Do not overwrite the v0.7.5.3 backup or earlier baseline files. If a saved v0.7.5.4 world contains persistent edits, test it on a copied save with v0.7.5.3 before deleting the v0.7.5.4 build.
