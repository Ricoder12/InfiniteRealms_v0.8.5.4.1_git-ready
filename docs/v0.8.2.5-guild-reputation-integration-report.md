## Implementation

Added `js/game/66-guild-reputation-integration-v0.8.2.5.js` with validated guild-to-shared-faction resolution, membership/standing accessors, and reference/state validation. Guild service and contract interactions now read the common membership and standing values through these accessors. Guild staff and membership information display the shared standing, and the contract board explains that only the existing membership requirement gates offers; no standing threshold was configured in the existing foundation.

Standing changes remain the ones already implemented in the shared faction system: joining awards +5, leaving costs 10, and existing regional event outcomes update standing. This step adds no new awards or penalties. Inquiry, opening a board, and accepting an offer do not change standing, public reputation, relationships, time, inventory, or money. Contract completion and its rewards remain out of scope.

There is no reusable centralized standing mutation helper in the source. Accordingly, this step did not invent one or reroute unrelated legacy event logic; guild screens consume the existing authoritative values through the v0.8.0 getter. The pre-existing join/leave functions remain authoritative for membership and their established standing deltas.

No per-guild reputation, standing threshold, rank, reward, or completion behavior is implemented. Browser presentation and real user saves require separate manual confirmation.
