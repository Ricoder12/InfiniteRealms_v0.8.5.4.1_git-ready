# Infinite Realms v0.8.7 — Social and Political Simulation Rules

**Status: approved by the user on 2026-10-24.** Implementation follows the proposal supplied by the user and the clarifications explicitly approved in the conversation.

## State and migration

Add `world.v087` with `schema: 1`, `npcs[npcId] = { ambition, ambitionProgress, rumors }`, and `politics[siteId][factionId] = { alliance, rivalry }`. Keep `npc.goal`, `world.journal`, `world.v086`, NPC identity, and existing relationship records as their authorities.

The five ambition enums are `ambition:wealth`, `ambition:security`, `ambition:influence`, `ambition:knowledge`, and `ambition:stability`. Progress is an integer from 0 to 100. An NPC's deterministic starting ambition is derived from the existing goal text: wealth/coin, protect/guard/safe, magic/learn, or power/rule; otherwise stability. Starting progress is 0 and rumors are empty.

Each settlement/faction pair starts with null alliance and rivalry. Links contain one canonical faction ID or null, and must be mutual and non-self-referential. NPC records are retained for known identities in the current character list and existing NPC registry/changes; unknown IDs, invalid sites, and unknown factions are ignored. For schema 1, valid fields are preserved while invalid individual fields receive deterministic defaults; absent or unsupported schema uses all defaults. Loading performs no ticks, rumor propagation, or political shifts.

## Daily processing

Run the following after the existing v0.8.6 daily tick succeeds, keyed by the same `character.daysLived` day:

1. Remove NPC rumors whose `eventId` is not the current active warning/escalation event. For each settlement in the active event's region, select up to two valid NPCs whose `homeSite` is that settlement using a deterministic shuffle seeded by world seed, day, settlement ID, and event ID. Add `{ eventId, tickHeard: currentDay }` only if absent. Keep at most five entries per NPC, removing oldest entries first.
2. Evaluate each NPC at their `homeSite`. Add 5 ambition progress when its condition is met: wealth, a regional transfer of more than one unit occurred there today; security, regional threat is 0 and security is above 80; influence, any local faction influence increased today; knowledge, Arcanum influence is above 50; stability, no warning or escalation is active in the region. Clamp progress to 0–100. At 100, reset progress to 0 and add 2 to that NPC's affinity, clamped to the existing −100–100 range. This reward repeats each time progress reaches 100; trust is unchanged.
3. Form political pairs from the settlement's v0.8.6 influence scores. A rivalry qualifies when one faction is at least 75 and the other at most 25. An alliance qualifies when both factions are at least 60. Sort candidate pairs by canonical faction ID and greedily choose disjoint reciprocal pairs, independently for alliances and rivalries. This gives each faction at most one link of each type. Recompute pairs daily; a link clears at both ends when it no longer meets its formation thresholds, and an eligible new pair can replace it.
4. On days divisible by 7, subtract 2 influence from each faction with an active rivalry, clamped to 0–100. If merchants have an active rivalry at a settlement, skip that settlement's v0.8.6 regional trade for the day. An existing alliance grants the allied faction +1 when its partner receives a positive v0.8.6 helped-event influence gain. Apply the bonus once to the original gain, without chains, and clamp at 100.

NPC ambition rewards use the existing character relationship record and NPC persistence helpers. Social/political changes are part of the daily simulation transaction: if that tick fails or rolls back, discard its v0.8.7 changes as well. There is no general action rollback in the existing systems; rollback scope is the daily tick transaction.

## Visibility

Show active ambition, progress, and unexpired rumors in the existing People/Dialogue UI. Show each settlement's current faction alliances and rivalries beside its existing v0.8.6 influence scores. Do not add political ownership changes, new faction standing, or other mechanics.
