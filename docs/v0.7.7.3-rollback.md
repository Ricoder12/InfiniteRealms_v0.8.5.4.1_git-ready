# Infinite Realms v0.7.7.3 — Rollback Instructions

The byte-exact accepted v0.7.7.2 standalone is included as:

`backups/InfiniteRealms_v0.7.7.2_accepted_baseline.html`

A release-level copy is also delivered as `InfiniteRealms_v0.7.7.3_backup.html`. Before release packaging, its SHA-256 is compared with the input `/mnt/data/InfiniteRealms_v0.7.7.2.html`; they must match exactly.

## To revert the game

1. Keep a copy of the current v0.7.7.3 save before replacing the game build.
2. Open `InfiniteRealms_v0.7.7.3_backup.html` (or the accepted-baseline copy inside `backups/`) instead of the v0.7.7.3 standalone.
3. Do not overwrite the v0.7.7.3 file; this allows comparing or returning to it later.
4. The v0.7.7.3 map view stores its selection and view scope in transient UI variables and does not add map-specific fields to the saved world.

The rollback artifact itself is not modified by this release. This change does not alter travel formulas or create geography data that would need a data migration.
