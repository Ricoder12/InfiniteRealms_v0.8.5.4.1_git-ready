## v0.7.3.6 anti-farming rules

The saved `world.v0736.earned` ledger records positive affinity/trust already received per NPC and interaction category. The configured lifetime caps are: talk 6/6; favor 0/4; spend time 6/4; advice 3/0; train together 4/4; work together 5/5; meal 6/4; personal task 8/6; tavern outing 6/4; campfire 6/6; romance 8/6; mentor training 3/6; bargain 0/3; sparring 3/3; farm work 0/4; guard reporting 0/4 (affinity/trust respectively). Relationship status changes and reconciliation keep their existing rules; reconciliation is not blocked by these caps.

The reward ledger is persisted after the action has completed, not only during the original action's earlier save call. Valid old cap/claim entries are not discarded when the ledger grows, so returning to an older NPC cannot reset its reward limit. This trades a small amount of save growth for durable anti-farming behavior.

## Patch/module map and rollback

The six isolated modules, in load order, are:

1. `js/game/27-npc-memory-reliability-v0.7.3.1.js`
2. `js/game/28-witness-based-reputation-v0.7.3.2.js`
3. `js/game/29-reputation-based-npc-reactions-v0.7.3.3.js`
4. `js/game/30-positive-reputation-v0.7.3.4.js`
5. `js/game/31-contextual-favors-information-v0.7.3.5.js`
6. `js/game/32-feedback-antifarming-regression-v0.7.3.6.js`

The patches wrap shared callbacks in order; boot must remain last. To revert a version in source, remove its module's `<script>` tag from `index.html`, delete the module, restore the version title, and rebuild with `node build.js`. Because later modules wrap some earlier callbacks, reverting an earlier patch from the current tree must also remove later dependent layers. For the safest exact rollback, use the matching untouched standalone backup instead of selectively removing an earlier dependency. The v0.7.3.6 immediate rollback is `backups/InfiniteRealms_v0.7.3.5_backup.html`.
