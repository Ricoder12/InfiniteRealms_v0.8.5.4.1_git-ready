## Defect found and fixed
A site with an unknown biome ID could use the Woodland fallback for display and also receive Woodland random encounters. The v0.7.6.6 guard now returns no habitat candidates and pauses uncontrolled random combat for unresolved biome references. It preserves the saved data, keeps recognized legacy labels working, and leaves settlement encounters, explicit scripted enemies, dungeon/boss starts, and controlled spar available.

## Important caveat
A passing VM suite verifies deterministic game logic and source integration, not every visual/browser interaction. Open the delivered HTML in a normal browser before final acceptance and test load/save, travel, gathering, hazards/recovery, scouting/hunting, and a combat reward.
