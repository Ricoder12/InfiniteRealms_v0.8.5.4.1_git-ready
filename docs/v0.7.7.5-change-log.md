# v0.7.7.5 Change Log

## Added

- `js/game/47-travel-route-integration-v0.7.7.5.js` as the canonical graph-backed integration layer.
- Validated edge resolution using `world.region.routes` plus endpoint route records as integrity checks.
- Direct preview information filtering for unsurveyed destinations.
- Verified graph-based multi-leg path planning and per-leg revalidation during execution.
- State snapshots and rollback for thrown direct-travel/segment operations.
- Regression tests for connection integrity, estimates, interruptions, discovery privacy, save/load, and map route consistency.

## Changed

- Map and local-exit route views now reflect verified canonical connections rather than orphaned local route records.
- Travel previews use neutral labels and unknown risk/terrain where discovery does not support disclosure.
- Current-location environmental hazard feedback remains; future unsurveyed endpoints do not disclose biome-specific warnings.
- UI shell metadata updated to v0.7.7.5.

## Preserved

- The accepted v0.7.7.4 direct-trip implementation and existing quote formulas.
- Existing transport names, fares, equipment/prerequisite checks, environmental hazard mechanics, encounter/event systems, and save schema.
- Existing map/location data and geographic IDs. No fake edges or new locations were created.

## Not included

- No new transport system, survival requirement, route-specific danger registry, terrain speed bonus, map-coordinate distance calculation, or comprehensive alternative-route planner.
