# Infinite Realms v0.8.3.6 — Association Tab and Assignment Gate

## Implemented behavior

- Adds a top-level Association tab with overview, membership, personal rank, shared Association standing, separate public reputation, known leadership/staff, branch locations, contracts, duties, active assignments, and supported history.
- Reads world organizations, NPC references, character membership and progression, contract records, and duty records already present in the save. It does not create a global member roster, fabricate personnel, or alter rank/exam records when the tab is rendered.
- Uses the existing contract offer markup and existing contract/duty actions. Contract objective validation, reward finalization, duty progress, credit, cancellation, and expiry remain in their existing services.
- A derived gate counts active records across every Adventurers' Guild branch. It blocks direct contract acceptance and duty acceptance as well as Association-page actions. A second request made while an acceptance operation is in flight is rejected.
- More than one pre-existing active record is preserved and shown as a conflict; no new assignment can be accepted. Malformed or quarantined assignment data disables new acceptance without rewriting it.
- Duties retain the existing 14 in-game day expiry and cancellation. Contracts have no cancellation or expiry in the accepted source; they release the slot only after the existing verified completion, reward receipt, and save operation succeeds.
- The shared slot is derived from authoritative contract and duty records; no duplicate slot field or save migration was added.

## Data gaps and limitations

- The source has no authoritative global adventurer registry, so only the current player's authoritative record can be shown. The interface states that the display is not a complete roster or leaderboard.
- Association leadership is shown only when `world.associationLeadership` resolves to the referenced existing NPC with the expected role. Otherwise the interface reports the record as unconfigured or unresolved.
- Branch services require the referenced receptionist to be present at its configured location. Other branches link to the World map; the Association tab does not fabricate travel actions.
- The v0.8.3.5 examination service remains unavailable in worlds without configured Grandmaster/delegated examiner authority.

## Starting point and rollback

The latest explicitly accepted source before this implementation was v0.8.3.4. The verified v0.8.3.5 package was a candidate, not an accepted release. This implementation uses the verified v0.8.3.5 candidate source tree while preserving that tree and its package unchanged; v0.8.3.4 remains the last accepted rollback. No save schema fields were added.

## Lifecycle policy

No new contract cancellation, failure, or expiry rule was introduced. Existing contracts use active/completed status and existing completion turn-in; existing duties use active/completed/cancelled/expired. A duty expiry releases the slot only after the expiration record saves. A failed expiry save rolls the progression back and keeps the slot blocked.
