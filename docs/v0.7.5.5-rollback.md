# Infinite Realms v0.7.5.5 — Rollback Instructions

## Roll back to accepted v0.7.5.4

1. Close the game tab.
2. Open `InfiniteRealms_v0.7.5.4.html` (the preceding accepted standalone build), or restore `backups/InfiniteRealms_v0.7.5.4_backup.html` from this source archive.
3. Keep a copy of any exported JSON save before loading it in another version. Do not overwrite the only copy of a valuable save while testing.
4. If v0.7.5.5 has modified the current browser autosave, load a pre-test manual save slot or import the saved JSON backup from the prior version. Avoid clearing site storage until you have exported anything you need.

## Source rollback

For a source working copy, restore `index.html` and remove `js/game/36-save-compatibility-regression-v0.7.5.5.js`. Remove the two v0.7.5.5 tests and three v0.7.5.5 documentation files if you want an exact source-only rollback. Rebuild with `node build.js` only after the rollback has been applied.

## Integrity note

The original v0.7.3.6 standalone baseline and accepted earlier standalone files are retained unchanged. This change set contains no v0.7.6+ feature work. Do not use the same browser autosave as the only rollback mechanism; retain a portable JSON export or the v0.7.5.4 version file separately.
