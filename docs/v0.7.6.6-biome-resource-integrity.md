The profile system continues to use the current site's `biomeId` as its primary source of truth. A recognized legacy label may resolve to a canonical profile without changing the stored label. An unrecognized biome gets a safe display fallback, but cannot provide gathering loot or a random habitat encounter.

## Runtime validation
`irValidateBiomeEcology(world)` aggregates the existing biome, resource, hazard, affinity, habitat, and geographic validation reports. It is diagnostic only: it does not repair, migrate, or regenerate a saved world. Corrupt references are reported and preserved for explicit recovery rather than silently redirected.
