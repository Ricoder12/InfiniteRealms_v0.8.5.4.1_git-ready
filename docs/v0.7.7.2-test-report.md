## Test-environment limitations
The browser test runs Chromium through Playwright with the standalone output loaded into an isolated page and an in-memory `localStorage` shim, because the restricted browser test environment does not provide a consistent local-file storage origin. It creates a deterministic test character/world; **a real player-exported save was not independently tested**. Save/world schema equality is checked in the test fixture around atlas navigation, and existing geographic/save migration suites pass. This does not replace a manual test with the user's own browser and save.
