## Implementation

Added `world.v086` with deterministic initialization and save normalization. Existing settlement condition values remain authoritative when valid; missing or invalid condition values use the existing v0.5 formulas. Each geographic region, including child regions, receives its own threat and resource pools. The regional panel displays those values, settlement conditions, faction influence, and the most recent action summary.

The existing daily world event loop now advances each unprocessed in-game day exactly once. It applies approved threat decay and event transitions, resource renewal, settlement pressure and recovery, bounded transfers through existing market records, and weekly influence normalization. Transfers respect shop services, choose shortages before surpluses in the specified item order, move up to five units, update the existing stock and category demand, and count as one market transaction. No market is created by simulation ticks.

Action summaries accumulate net changes over multi-day UI actions, including event and contract changes in the same action. Existing save normalization migrates old saves at their current day without catch-up ticks, and repeated loads without elapsed time are idempotent. Daily tick updates roll back their regional, settlement, and market changes if the tick fails.
