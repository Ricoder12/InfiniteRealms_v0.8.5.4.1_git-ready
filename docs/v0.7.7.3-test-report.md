## Browser coverage

The Chromium suite used deterministic seed `IR-WORLD-MAP-772-DETERMINISTIC` and created a fresh character. It checked atlas/regional/local display, phone-width layout, no horizontal overflow, current-location highlight, known and disconnected destination inspection, direct-route preview without movement before confirmation, reciprocal route-record validation, missing optional geography fields, hidden data filtering, preservation of a selected stable `geoId` through atlas/regional/local transitions, and no uncaught browser errors.

The localStorage interface was replaced with an isolated in-memory shim for the browser test. This verifies map-screen behavior but is not a substitute for testing a real exported player save file.

## Known model limitations

- No real player-exported save was supplied; the save compatibility regression suites and deterministic new-world fixture were used.
- This generated world contains one populated region with 49 site records and no populated continent/country hierarchy. The world atlas can navigate to the existing region but cannot display real world-scale landmasses that do not exist in data.
- The saved geography contains site coordinates and route relationships, not traced coastlines, rivers, ridge polygons, crossings, political boundaries, road/path polylines, or settlement street/building geometry. These are explicitly not drawn or inferred.
- The local view is a truthful location-detail/services/known-exits panel, not a spatial settlement map, because no local geometric data is available.

Travel formulas, route eligibility, danger, exploration rewards, biome effects, world generation, and saved discovery progress were left on their existing code paths.
