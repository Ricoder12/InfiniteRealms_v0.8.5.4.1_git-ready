# Infinite Realms v0.7.6.2 — Change Log

## Base and preservation

- Built from the accepted v0.7.6.1 source project.
- Preserved `InfiniteRealms_v0.7.6.1_backup.html` unchanged; SHA-256 `ee4d38bb6a80a525f147a39580f1579f1eedb77b6f66a69f7a52dbb672e3230e`.
- Existing standalone versions and the original v0.7.3.6 baseline were not modified.

## Changes

1. Extended the existing `IR_BIOMES` gathering pools with biome-specific weightings using only item IDs already present in the inventory registry.
2. Removed nonsensical active resource outcomes such as desert fishing returning stone and mountain herbalism returning ore. Inactive action pools do not award resources.
3. Added a legacy `cave` profile alias to the existing mountain resource profile without rewriting a saved site's `biomeId`.
4. Made gathering, forage, and scouting stop safely when the actual current location or its biome cannot be resolved. These actions no longer use generic woodland fallback loot for a broken reference.
5. Added `js/game/38-biome-resources-gathering-v0.7.6.2.js` for exact current-site resolution, resource reference validation, and action-boundary checks.
6. Retained existing loot success chances, per-action energy/time costs, skills, tool/equipment requirements, recipes, item weights, carrying capacity, XP, racial talents, and item-condition/equipment systems.
7. Added focused tests for actual gathering in all supported biomes, current-location targeting, invalid references, item validity, failed-action costs, skill scaling, crafting compatibility, save normalization, and no racial affinity changes.

## Intentional exclusions

No racial affinity, new items, new recipes, new crafting rules, environmental hazards, new map views, dynamic economy, factions, or political features were added. No world layout or save-schema version change was introduced.

## Existing test fixture alignment

Two earlier gameplay test fixtures were narrowed to use a valid forest site for their direct woodcutting call. This corrects test setup to respect biome availability; assertions and gameplay code for those prior regression checks were not otherwise changed.
