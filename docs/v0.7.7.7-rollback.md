# v0.7.7.7 rollback instructions

## Rollback target

Use `backups/InfiniteRealms_v0.7.7.6_accepted_baseline.html` (downloadable as `/mnt/data/InfiniteRealms_v0.7.7.6_rollback.html`) to return to the supplied v0.7.7.6 starting build.

## Provenance and verification

The rollback file was copied byte-for-byte from the v0.7.7.6 standalone working build supplied as the starting point for this update. Its SHA-256 is recorded in `docs/v0.7.7.7-sha256sums.txt`. The local rollback copy and the retained source-tree baseline are checked against each other as part of release packaging.

## How to roll back

1. Close the v0.7.7.7 browser tab.
2. Open the v0.7.7.6 rollback HTML file.
3. If continuing an existing save, use the game's normal Load workflow. Do not copy any new data fields: v0.7.7.7 adds no save-schema fields and map view selection is transient UI state.

The prior v0.7.7.5 accepted baseline remains preserved at `backups/InfiniteRealms_v0.7.7.5_accepted_baseline.html` as an additional historical fallback.
