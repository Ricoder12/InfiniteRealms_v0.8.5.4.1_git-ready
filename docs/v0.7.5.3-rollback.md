# v0.7.5.3 Rollback Instructions

## Safest rollback

1. Close the game tab and keep any exported saves separately.
2. Replace the v0.7.5.3 standalone HTML with the untouched `InfiniteRealms_v0.7.5.2_backup.html`.
3. If using the source project, restore the v0.7.5.2 source archive or remove only the v0.7.5.3 additions and revert the `index.html` title/script include.
4. Do not replace the v0.7.5.2 baseline with a modified build.

## v0.7.5.3-specific changes

- Added `js/game/34-geographic-hierarchy-connections-v0.7.5.3.js`.
- Added its script include and version title in `index.html`.
- Added v0.7.5.3 tests and documentation.

The v0.7.5.2 stable-ID module and existing map renderer compatibility changes are preserved in the source version. The standalone v0.7.5.2 backup is intended as the one-file rollback target.
