# Infinite Realms v0.7.7.4 — Change Log

## Added

- Biome-aware illustrative local scenes for settlements and wilderness.
- Settlement-size-dependent arrangements for hamlets, remote settlements, villages, towns, and cities, using deterministic visual slots.
- Interactive facility markers derived only from recorded site services and mapped to existing UI tabs/action handlers.
- Visual references to real site-bound NPC records where available; existing guards and other known occupations may link to the People directory without creating a building or NPC.
- A player-position marker that clearly states exact local position is not tracked.
- Neutral handling for unsurveyed locations and safe rendering when optional site data is missing.

## Compatibility and constraints

- Preserves atlas/regional/local navigation and existing route/travel controls.
- Does not add new save fields or mutate the saved world while rendering.
- Does not change travel duration, travel danger, route validity, discovery rewards, biome effects, NPC schedules, occupations, or availability.
- Does not add interactive services, NPCs, POIs, interiors, roads, rivers, crossings, or local movement mechanics.
- Visual positions for buildings and scenery are not world data; all scenery besides explicitly registered destination actions is decorative.
- The regional detail renderer was minimally hardened so an unsurveyed current location does not expose its biome through route-terrain labels or neighboring-unvisited biome labels. The route actions and travel formulas are unchanged.

## Files

- Added `js/game/46-local-map-v0.7.7.4.js`.
- Updated `css/world-map.css` for local scene styling.
- Updated `js/game/45-regional-map-v0.7.7.3.js` to conceal biome-specific route descriptors while the current site is unsurveyed.
- Added `tests/v0.7.7.4-local-map.test.js` and `tests/v0.7.7.4-browser-smoke.py`.
- Updated README and release documentation/evidence.
