# Infinite Realms v0.7.6.1 — Rollback Instructions

## Roll back the playable build

1. Close the running game.
2. Keep a separate copy of any save export you have. This release does not intentionally migrate the save schema, but always keep a backup before changing builds.
3. Open `InfiniteRealms_v0.7.6.1_backup.html`. This file is the unchanged accepted v0.7.5.5 standalone build, not a reconstructed substitute.
4. If using the source project, restore the saved v0.7.5.5 baseline from `backups/InfiniteRealms_v0.7.5.5_backup.html` or use the accepted v0.7.5.5 source archive separately.

## Scope of rollback

The v0.7.6.1 changes are limited to biome data/accessors, profile-driven reads in existing consumers, validation, tests, and documentation. No v0.7.6.1-specific save-schema version bump or per-site biome-profile snapshot is added. Rollback restores the older runtime; it does not reverse any player actions performed after the newer build was opened.

## Baseline identity

The final release instructions identify the v0.7.5.5 rollback by SHA-256. Verify the provided file using `sha256sum InfiniteRealms_v0.7.6.1_backup.html` and compare it with the hash in the release report before relying on it.
