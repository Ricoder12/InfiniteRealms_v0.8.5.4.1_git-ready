# Infinite Realms v0.7.6.6 — Change Log

## Scope
Stabilize the biome profile, gathering, racial affinity, hazard, and monster habitat systems introduced in v0.7.6.1–v0.7.6.5. No new gameplay feature family was added.

## Changes
- Added `js/game/42-biome-ecology-stabilization-v0.7.6.6.js` with a combined ecology-integrity report for biome resources, gathering availability, hazards, affinities, monster habitats, and saved geographic references.
- Fixed a confirmed safety defect: an invalid saved biome ID could silently fall back to Woodland and generate a Goblin or other Woodland encounter. Uncontrolled biome encounters now pause with a clear message when the location biome cannot be resolved; the original saved biome value is preserved.
- Preserved valid legacy biome labels, including `cave` resolving to Mountain, plus settlement encounters, explicit scripted fights, dungeon bosses, and controlled spar.
- Added 32 stabilization regression tests and a seven-check standalone HTML smoke test.
- Updated project documentation and preserved the accepted v0.7.6.5 standalone as the rollback baseline.

## Explicitly unchanged
- Biome IDs, resource/item definitions, crafting recipes, race data, racial traits, affinity values, hazard profiles, enemy definitions, danger/reward statistics, world generation, save schema, and existing navigation/UI structure.
- No saved world is regenerated and no invalid saved biome ID is silently rewritten.
