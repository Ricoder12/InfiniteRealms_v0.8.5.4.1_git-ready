# Infinite Realms v0.7.8.5 — Test Report

## Release scope

Descriptive government, existing-NPC leadership references, capital metadata and read-only summary helpers. No political gameplay and no schema migration.

## Results

- Focused Node political-government/leadership/capital assertions: 23/23 passed.
- Full Node regression files and standalone smoke suites: 34/34 passed.
- Chromium government/leadership/capital suite: 16/16 passed.
- Chromium save compatibility/integration: 21/21 passed.
- Chromium regional hierarchy: 15/15 passed.
- Chromium unified map/Character UI: 22/22 passed.
- Chromium travel: 10/10 passed.
- Total across five distinct Chromium suites: 84/84 assertions passed; no uncaught browser/console errors recorded.
- JavaScript syntax: 100 JavaScript files under `js/` and `tests/` passed; `build.js` passed.
- Python browser-test syntax: 20/20 scripts passed `py_compile`.
- Standalone build passed. Accepted candidate copy matches built standalone byte-for-byte. Rollback copies match their preserved baseline files. Source ZIP integrity passed.

## Focused scenarios

The new tests covered complete, partial, and empty political metadata; supported/unsupported government types; known, missing and ambiguous leader IDs; existing NPC resolution through the persisted-person overlay; valid and invalid capital references; capitals with no territorial ownership data; capital-to-explicit-territory consistency; controlled-region counts based only on explicit regional owner/governor links; non-mutating summary retrieval; repeated normalization; and an actual browser save-slot round trip preserving government, capital and leader references.

The cross-system save suite generated saves using accepted v0.7.6.6 and v0.7.7.7 game builds and loaded them in the current candidate. It verified the 49-site world, unique geographic and route IDs, exploration/discovery, inventory, equipment, NPC data, relationships, reputation, progression, travel and post-travel reload. It also exercised the new-game path.

## Test suite maintenance

Existing regression tests that hard-coded the prior release title or old script/module order were updated to expect v0.7.8.5. Their functional assertions were retained. The three historical standalone smoke suites passed after updating the single old version-title expectation.

## Baseline qualification

The requested accepted v0.7.8.4 build was not present in the available workspace. Tests were run against a candidate built from the latest verifiable accepted v0.7.8.3 source/build. No claims are made about changes unique to a missing v0.7.8.4 build. Formal acceptance against the originally requested starting point is pending that artifact or explicit approval to use v0.7.8.3 instead.

## Known limitations

The game has no single global NPC directory. A leader reference resolves only if the existing person/NPC is present in a supported saved store; unmaterialized residents cannot yet reliably serve as an off-site ruler. The update adds a data retrieval helper, not a new political UI. Personal/exported player saves were not supplied.
