## Implementation summary

Added receptionist-based duty offers for Goblin defeats, Bitterleaf gathering, and Field Bandage delivery. Objective tracking uses confirmed combat victory records, actual item inventory deltas from herbalism, and item removal at the issuing guild receptionist. Event IDs and a recoverable pending-gather marker prevent duplicate progress across retries and saves. Duties can be cancelled, expire after 14 in-game days, and retain history. Completed duties award 1 personal duty credit up to 2 per category per character per `character.daysLived`; completed work beyond the cap receives no credit. Credit never promotes rank.

The personal record is `character.adventurerProgression`, separate from the existing general XP `character.progression`, guild membership, standing, and public reputation. Missing records receive F rank and empty fields. Valid rank and unknown fields are preserved. Invalid records are left unchanged, marked quarantined in `character.adventurerProgressionIntegrity`, and cannot be used by duty operations.

## Known limits

- Browser layout, real click behavior, and screenshot evidence remain unverified.
- Compatibility was checked with generated/fixture saves through the production normalizer, not user-exported saves.
- Only the three approved templates are supported. Other duty types remain unavailable.
- The existing organization model shares the Adventurers' Guild membership faction across generated guild organizations; the implementation follows that existing authoritative membership model.
- If browser storage itself fails, normal game persistence can fail as before; delivery rolls back its in-memory item/progression changes when `persist()` reports failure. Gather/combat retain the existing game's persistence failure semantics.
