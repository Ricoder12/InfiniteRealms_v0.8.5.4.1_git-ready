# v0.7.6.4 Change Log — Racial Biome Affinity

## Added
- Added `js/game/40-racial-biome-affinity-v0.7.6.4.js` with affinity data for all eight existing races across all nine supported biome IDs (72 race-biome cells).
- Added one shared resolver for gathering and hazard modifiers, plus validation for race coverage, biome coverage, and modifier bounds.
- Integrated modest gathering-success bonuses into the existing gathering chance calculation.
- Integrated strong-affinity energy reduction into the existing environmental hazard tick; health damage and existing Survival/armor mitigation remain unchanged.
- Added concise affinity feedback to the existing World and Adventure views.
- Added 20 focused tests for matrix coverage, modifiers, hazard integration, gathering integration, UI feedback, and save compatibility.

## Deliberately unchanged
- Character creation, race definitions, base attributes, skills, racial talent trees, level progression, combat calculations, world generation, biome profiles, resource pools, routes, and save schema.
- No biome access restrictions, racial penalties, new survival meters, new races, or new UI navigation surfaces.

## Source files changed
- `index.html`: version title and new module script.
- `js/game/05-progression-economy-v0.4.js`: shared affinity gathering chance added to the existing chance formula.
- `js/game/39-environmental-hazards-v0.7.6.3.js`: shared affinity reduction applied to hazard energy loss only.
- Added `js/game/40-racial-biome-affinity-v0.7.6.4.js`.
- Added `tests/v0.7.6.4-racial-biome-affinity.test.js` and this version's documentation.

## Follow-up debug pass
- Fixed an invalid-race edge case: unknown/corrupt race IDs now receive neutral affinity modifiers instead of inheriting Human's adaptive gathering bonus. The character record is not silently rewritten.
- Added a deterministic integration test proving strong affinity changes the real gathering outcome, not just the resolver output.
- Re-ran all 18 regression suites, including older v0.7.3.x, v0.7.5.x, and v0.7.6.2–v0.7.6.3 tests; all passed.

The accepted v0.7.6.3 standalone HTML remains preserved as a byte-identical rollback file.
